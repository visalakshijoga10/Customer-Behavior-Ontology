# 🛒 Customer Behavior Ontology

## 📖 Project Overview

This project was developed as part of the **Big Data** course during my Master's in Computer Science (Software Engineering).

The project focuses on integrating structured and unstructured customer data to analyze customer behavior and develop an ontology that models relationships between customers and products using Semantic Web technologies.

The ontology was implemented using Python and RDFLib in Google Colab, exported in RDF/XML format, validated using the W3C RDF Validator, and visualized as a graph.

---

## 🎯 Objectives

- Integrate structured and unstructured customer datasets.
- Analyze customer transactions and product reviews.
- Develop an ontology representing customer-product relationships.
- Generate RDF/XML using RDFLib.
- Validate the ontology using the W3C RDF Validator.
- Visualize customer-product relationships as an ontology graph.
